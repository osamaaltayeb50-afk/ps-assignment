# PS Assignment

Scripts and configuration files for the ProgressSoft technical assignment (Linux, SQL, Tomcat, DevOps).

- `linux/` - system information script, user/package setup, firewall rules
- `sql/` - Oracle DDL, queries, function F_HR_QUERY and procedure P_COPY_EMPLOYEE
- `tomcat/` - Tomcat 9 on port 7070 behind Nginx, Vagrantfile and provisioning script
- `devops/` - Dockerfile with a sample WAR, Docker commands, Kubernetes (K3s) manifests

Docker image: `osamaaltayeb/tomcat-sample:1.0` on Docker Hub.
